# 1.3.0: every benchmark on the release code, on a loaded machine

Same machine and harness as the earlier results, every benchmark class run on the 1.3.0 code, commit `c8707ba`:

```
BenchmarkDotNet v0.15.8, Windows 11 (10.0.26100.9448/24H2)
Intel Core Ultra 7 255H 2.00GHz, 16 logical and 16 physical cores
.NET SDK 10.0.402, runtime .NET 10.0.13, X64 RyuJIT x86-64-v3, DefaultJob
```

## What 1.3.0 changed in these numbers

Nothing in the dispatch code. Between 1.2.0 and 1.3.0 the runtime and the code the generator writes for dispatch
are unchanged; the message map is off by default, and with it off the generated code is the same. The only
files in the runtime package that changed are its MSBuild props and targets.

This run was not on a quiet machine. It ran short of memory: the full run was stopped after six classes, and
the telemetry and scale classes were run again on their own afterwards. Every library is slower than in the
1.2.0 run by about the same share, MediatR included: its send took 46.8 ns here against 37.1 ns then, outside
the 32 to 42 ns it moved between across the earlier runs. The README keeps the 1.2.0 numbers, which measure the
same dispatch code on a quiet machine. Read these tables for the ratios, and for each library against MediatR
in the same table.
