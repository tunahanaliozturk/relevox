# 1.2.0: every benchmark on the release code

Same machine and harness as the earlier results, every benchmark class run on commit `c144211`, the 1.2.0 code,
one class at a time:

```
BenchmarkDotNet v0.15.8, Windows 11 (10.0.26100.9448/24H2)
Intel Core Ultra 7 255H 2.00GHz, 16 logical and 16 physical cores
.NET SDK 10.0.402, runtime .NET 10.0.13, X64 RyuJIT x86-64-v3, DefaultJob
```

## What 1.2.0 changed in these numbers

Telemetry is off in every benchmark but `TelemetryBenchmarks`, and off it costs a call one flag read. The send,
pipeline, publish and stream rows sit where 1.1.0 put them, within this machine's noise, which for MediatR's own
send runs from 32 to 42 ns across the runs published so far. Compare each library with MediatR in the same table.
