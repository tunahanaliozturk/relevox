# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, criticise code rather than people, and keep discussions about the
work. Harassment of any kind is not tolerated.

To report a problem, open a [private security advisory](https://github.com/tunahanaliozturk/capar/security/advisories/new)
with "Conduct" in the title, so the report is visible only to the maintainer. It will be read and answered
in confidence.
